# 🌟 Planora - User Feature Documentation

**Release Identifier**: Planora Core v1.0.0  

Planora provides an integrated productivity experience designed specifically for academic students and busy professionals.

---

## 🔐 1. Authentication & Security
- **Registration**: Quick sign-up with instant default category setup.
- **Secure Login**: JWT-based session management with encrypted token storage.
- **Data Protection**: Multi-tenant data scoping ensures private user data remains strictly isolated.

---

## 📊 2. Interactive Dashboard
- **Daily Overview**: Central hub displaying today's tasks, class timetable slots, habit check-in status, and upcoming deadlines.
- **Productivity Score**: Dynamic visual calculation reflecting task completion rates and streak continuity.
- **Quick Actions**: One-click task creation, habit check-ins, and AI assistant access directly from the home screen.

---

## 📝 3. Task Management
- **Full CRUD Support**: Create, edit, filter, and delete tasks.
- **Priority Matrix**: Classify tasks by priority (`LOW`, `MEDIUM`, `HIGH`, `URGENT`).
- **Overdue Tracking**: Automatic visual flags for overdue tasks based on due date and completion state (`completedAt`).
- **Category Filtering**: Organize tasks by custom category tags with color coding.

---

## 📅 4. Events & Calendar Integration
- **Unified Calendar Grid**: Integrated day, week, and month views displaying both fixed events and due tasks.
- **Recurrence Support**: Flexible recurring events (Daily, Weekly, Monthly, Yearly).
- **Conflict Highlighting**: Visual indicators when scheduled events overlap with existing commitments.

---

## 📚 5. Academic Timetable Management
- **Weekly Schedule Grid**: Visual 7-day timetable matrix representing academic class slots (Slots 1–10).
- **Course Cataloging**: Store course codes, rooms, lecturers, class types (Theory/Practice), and credits.
- **Active Semester Toggle**: Manage multiple semester schedules while keeping one active semester live on the calendar.

---

## 🔥 6. Habit Tracking & Streaks
- **Streak Calculation**: Tracks current consecutive streaks and records historical best streaks.
- **Daily Log Check-in**: One-tap daily habit logging with custom notes.
- **Target Frequency**: Set custom target weekly frequencies (e.g. 5 days/week).

---

## 👤 7. Profile & Academic Portfolio
- **Student Metadata**: Store university name, major, student ID, GPA, and completed vs total credit progress.
- **Personal Bio**: Custom student bio and avatar presentation.

---

## ⚙️ 8. User Settings & Customization
- **Theme Selection**: Toggle between Light Mode, Dark Mode, and System Theme.
- **Notification Preferences**: Control email alerts, push notifications, and deadline lead times (e.g. 24h before due date).
- **Security Settings**: Password change workflow with verification of current password.

---

## 🔔 9. In-App Notifications
- **Real-Time Badges**: Visual unread notification badge counter on navigation bar.
- **Categorized Alerts**: Deadline warnings, habit streak milestones, and system updates.
- **Mark as Read**: Individual notification status toggle and "Mark All as Read" bulk operation.

---

## 🤖 10. AI Smart Assistant & Advisory Scheduling

> [!IMPORTANT]
> **Advisory Nature of AI**:
> - **AI is strictly advisory**.
> - **AI NEVER automatically alters or inserts schedule records into your database without explicit permission**.
> - Every schedule suggestion generated by AI must be explicitly reviewed and accepted by the user before database insertion.

### Key AI Features:
1. **AI Task Prioritization**: Analyzes pending tasks, due dates, and priority scores to recommend an optimized execution order.
2. **AI Smart Free-Slot Scheduling**: Scans open gaps between calendar events and class timetables to propose dedicated focus study sessions.
3. **AI Productivity Assistant**: Conversational assistant answering queries about schedule conflicts, time management tips, and workload balance.
4. **Safe Default Mode**: When `AI_PROVIDER=none`, AI features gracefully present informative fallback guidance while the rest of Planora remains 100% functional.
